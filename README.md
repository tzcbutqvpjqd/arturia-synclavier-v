## Overview

Arturia Synclavier V recreates the legendary New England Digital Synclavier, the pioneering FM additive synthesizer and sampler used in 1980s film scores and pop productions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Synclavier V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **FM+Additive** | FM synthesis combined with additive resynthesis for complex timbres |
| **Harmonic Editing** | Per-partial amplitude and frequency editing in the additive engine |
| **Timbre Frame** | Morph between multiple FM frames over time for evolving sounds |
| **Sample Playback** | Original 16-bit sample playback with pitch and looping control |
